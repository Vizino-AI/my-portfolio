# Vizino AI

A technical studio in Ottawa, Canada, helping non-technical founders turn
vibe-coded prototypes into launch-ready MVPs.

This repository is the studio's website, **<https://portfolio.vizino.ai>**,
which is mostly its blog.

## What we write about

- **Beyond the Vibe**: a series on common vibe-coding pitfalls, the daily
  habits that fix them, and how to shape a workspace your AI agents can do
  their best work in. Start with
  [Part 0, The Map](https://portfolio.vizino.ai/blog/beyond-the-vibe-0-the-map).
- **AI Agents**: notes from building AI agents for real products.
